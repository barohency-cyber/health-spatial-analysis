# 复试讲解卡：2 分钟讲清这个项目

## 一句话版本

我用 2SFCA 测度医疗资源空间可达性，再用 LISA、SLM/SEM 和 GWR 分析空间格局、空间依赖和空间异质性，并用 QGIS + Python 做成可复现项目。

## 30 秒版本

我研究的是医疗资源空间可达性。第一步用 2SFCA：先算每家医院在 5 公里内的“床位/竞争人口”供需比，再把每个社区能覆盖到的医院供需比加总，得到人均资源可得性。结果发现可达性不是随机分布，市中心是高-高聚集，边缘是低-低聚集；空间误差模型比普通回归更合适。最后用 GWR 发现可达性的关联在市中心更强、边缘更弱。

## 2 分钟版本

**背景**：医疗资源不均衡，不只取决于“有多少家医院”，还取决于居民能不能到达、要不要和周边人竞争。

**方法**：我用两步移动搜索法。第一步，以每家医院为中心，把 5 公里内的社区人口加总，得到这家医院的供需比；第二步，对每个社区，把它能覆盖到的所有医院的供需比加起来，就是该社区的人均资源可得性。这样同时考虑了供给竞争和跨社区就医。

**数据**：目前仓库里是模拟的 120 个社区、15 家机构，方便复现；换成真实数据只需要两张 CSV，QGIS 导出经纬度即可。

**结果**：5 公里内覆盖 98% 的人口，但每千人床位中位数 17.86，P90/P10 约 7.6，空间上并不均衡。LISA 显示市中心 20 个高-高聚集、东北和西南 12 个低-低聚集。空间回归里，普通 OLS 残差有显著空间自相关，SEM 的 λ 是 0.805，AIC 最低，说明空间依赖主要在误差项。GWR 进一步显示，可达性的关联在市中心约 0.03，边缘约 0.015。

**局限**：目前是直线距离，不是路网；空间回归是观察性设计，不能直接说因果；GWR 对带宽敏感，我做了 k 从 20 到 60 的敏感性分析，k ≥ 25 后局部系数方向基本稳定。

## 老师可能追问

### 1. 为什么用 2SFCA，不直接用“最近医院距离”？

最近距离只回答“离得远不远”，没有考虑医院容量和居民竞争。2SFCA 同时考虑供给、需求和距离阈值，更适合比较不同区域的人均资源可得性。

### 2. 直线距离和路网距离差在哪？

直线距离会高估可达性，尤其是河流、铁路、山体阻隔的地方。正式论文如果写“路网可达性”，必须用路网 OD 或导航 API 的出行时间，不能只改文字。

### 3. Moran's I 和 LISA 有什么区别？

全局 Moran's I 判断整体有没有空间聚集；LISA 进一步定位哪些社区是高-高、低-低或异常值，并做局部显著性检验。全局显著不代表每个局部都显著。

### 4. SLM 和 SEM 怎么选？

SLM 假设邻居的因变量会直接影响本社区，SEM 假设空间依赖在误差项。不能只看 R²，要比较 AIC/BIC、空间参数显著性和残差空间自相关。我的结果里 SEM 的 AIC 更低、残差 Moran's I 不显著，所以更偏向 SEM。

### 5. GWR 的局部系数能当因果效应吗？

不能。GWR 是探索性空间异质性方法，局部系数会受带宽、局部共线性和异常值影响。我做了带宽敏感性分析，并且只把它作为“关联在空间上是否变化”的证据。

### 6. 你的数据合规吗？

仓库里只有程序生成的模拟数据，没有真实边界、地址或个体问卷。真实数据会放在本地私有目录，公开仓库只放聚合结果和脱敏数据。

## 演示顺序（现场）

1. 打开在线地图，点一个市中心社区和一个边缘社区，对比每千人床位；
2. 展示 LISA 图，指出高-高和低-低；
3. 展示模型比较表，说明为什么选 SEM；
4. 展示 GWR 图，说明中心强、边缘弱；
5. 主动说局限：直线距离、观察性设计、带宽敏感性。
